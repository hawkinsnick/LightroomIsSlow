# Portable AI skill protocol — Phase 11

The skill protocol is transport- and vendor-independent. It defines semantic commands, accepted normalized inputs, and reasoning constraints without assuming ChatGPT, another AI product, Windows, or macOS.

An AI host may expose these commands through plugins, function calling, MCP-style tools, local IPC, a desktop bridge, or another authorized mechanism. Those transports are integrations, not part of the diagnostic science.

The deterministic Core remains authoritative for findings. The AI layer orchestrates, explains, compares, and requests follow-up experiments.
